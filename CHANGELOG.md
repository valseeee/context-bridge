# Changelog

## 0.1.0 — 2026-11-05

- Initial ContextBridge Agent Skill with create, project handoff, update, cleanup
  preview and host migration workflows.
- Eight statement categories, traceable evidence, uncertainty, current/history
  separation, preserved supersession and unresolved conflicts.
- Project Only default; explicit Work, Personal and Full Review scopes.
- Privacy screening, untrusted-source handling and inert Codex/Claude Code snippets.
- Optional dependency-free Python validator and package renderer with a v1.0 JSON contract.
- Bilingual documentation, synthetic behavioral scenarios and recorded validation.

Actual test results and compatibility limits are recorded in
[tests/evaluation.md](tests/evaluation.md). Product-specification version 1.1 is
distinct from this software release 0.1.0 and context schema 1.0.
