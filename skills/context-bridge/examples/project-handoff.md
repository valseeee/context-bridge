# Handoff example

Request: "Prepare Harbor so I can continue it in Codex."

After reviewing supplied project notes, generate only the useful topic files and
`adapters/codex.md`. Do not modify the receiving repository's `AGENTS.md`.

Example HANDOFF:

> Continue the existing project using this package. Read README.md, then the
> listed constraints, current tasks, decisions and open questions. Treat source
> claims with their recorded confidence and dates; inferences are unconfirmed
> and history is not current state. Resolve blocking conflicts before acting.
> Respect explicit constraints and check volatile facts against the project.
> Summarize your understanding and propose the next actionable step without
> repeating questions already answered by the package.

Include only filenames that actually exist in this package. A handoff is a
navigation prompt, not an invitation to upload sources to another service.
