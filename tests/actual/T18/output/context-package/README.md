## 证据与时效

共提取 5 条信息。每条均记录来源行号；第 3 行明确标注为用户陈述，其他行未注明说话人。`verified` 表示直接有用户明确陈述支持，`reported` 表示笔记记载、未经独立核实；两者都不代表已检查项目的实际实现。

`current` 表示原文中有效、未被取代的内容，不代表截至 2026-11-05 已核实仍然成立。来源和各条目的日期均保留为 `null`，不以包创建时间代替。增量索引的进度可能变化，接手时应核实；不能推定它已完成或已取消。没有仅因日期未知而废弃明确约束。
